# dns-reducing-sugar-protocol
Simplified DNS Protocol for Reducing Sugar Determination
1.Add 1.0 ml of standard solution and sample solution to each tube. 
2.Add 2.0 ml of DNS reagent to each tube (standard solution and sample solution). 
3.Mix on a vortex mixer, and then place them in a boiling water bath for 5 min. Begin timing when the tube is placed in the hot water; each tube must remain in the boiling water for the same amount of time. 
4.Remove each test tube from the boiling-water bath at the proper time, the test tubes are cooled down thoroughly by immersing them into cold water immediately, and then add 7.0 ml of distilled water to each tube. 
5.Read the optical density of the final colored solutions at 540 nm using the standard solution ID 1 (0 mg glucose/ mL) as a blank (control).
